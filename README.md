# ReadTech · เพื่อนฝึกอ่าน

เปิดเว็บแล้วฝึกได้ทันที ไม่มีบัญชีผู้ใช้ ไม่มีการเชื่อมต่อฐานข้อมูล ไม่มีคะแนนหรือดาวสะสม

## บทเรียนของฉัน

- **พยัญชนะ 16 ตัว:** ก ข ต น / บ ผ พ ม / ง ร ล ช / ส ฟ อ ฮ ตัวละ 6 กิจกรรม: รู้จักกันก่อน → ดูและฟัง → แยกตัวที่คล้ายกัน → ภาพกับพยัญชนะต้น → ฟังแล้วเลือก → เขียน
- **สระ 18 เสียง:** อะ อา อิ อี อึ อือ อุ อู เอะ เอ แอะ แอ โอะ โอ เอาะ ออ เออะ เออ สระละ 3 กิจกรรม: รู้จักกันก่อน → ฟังแล้วเลือก → เขียน
- **ผสมคำ 3 รูปแบบ:** เลือกการ์ดพยัญชนะ 16 ตัวก่อน แล้วจึงแสดงการ์ดกิจกรรม 3 แถว กดกิจกรรมเพื่อฝึกคำทีละคำตามลำดับ พร้อมจำจุดฝึกเดิม: ประสมคำง่าย (16 ตัว × 8 สระแรก ถึงอู = 128 คู่), เติมส่วนที่หาย และเรียงรูปคำ (รูปแบบละ 16 × 18 = 288 คู่) ฝึกให้ครบสระของพยัญชนะตัวแรกแล้วจึงเปลี่ยนพยัญชนะ บางคู่เป็นพยางค์สำหรับฝึกเสียง ไม่ใช่คำศัพท์ที่มีความหมาย

ภาพในรู้จักกันก่อนโยก กระเด้ง และขยับซ้ายขวา ปิดได้ด้วยโหมดสงบหรือการตั้งค่าลดการเคลื่อนไหวของอุปกรณ์ ตอบถูกมีป๊อปอัปและเสียงฉลอง ตอบผิดมีเสียงสั้นเบา ๆ พร้อมป๊อปอัปให้ลองใหม่หรือขอตัวช่วย ปิดได้ในการตั้งค่าเสียงตอบคำถาม กิจกรรมเขียนมีตัวอย่างขนาดใหญ่และลูกศรบอกทิศทาง ซ่อนลูกศรได้ และมีรูปพร้อมชื่ออยู่ภายในกรอบเขียนเฉพาะพยัญชนะ เป็นการฝึกตามแบบแล้วกดเสร็จแล้ว ไม่ตรวจลายมือหรือให้คะแนน

## จำจุดฝึกเฉพาะเครื่อง

ใช้ `localStorage` ชื่อ `readtech-open-progress-v1` จำหมวด ตัวที่เลือก กิจกรรม ชิ้นคำที่เรียง และเส้นที่เขียนไว้ เปิดเว็บอีกครั้งแล้วกด **ฝึกต่อจากเดิม** ได้ สถานะมีเริ่มฝึก/กำลังฝึก/ทำครบแล้ว ไม่มีข้อมูลรายบุคคล

**เริ่มใหม่** จะถามยืนยันก่อนล้างความก้าวหน้าสำหรับผู้เรียนคนถัดไป โดยคงการตั้งค่าเสียงและขนาดตัวอักษร และไม่ล้างข้อมูลเว็บไซต์อื่นหรือข้อมูล ReadUP เดิม ข้อมูลอยู่เฉพาะเบราว์เซอร์นี้ การล้างข้อมูลเว็บไซต์หรือโหมดไม่ระบุตัวตนอาจทำให้ไม่จำจุดฝึก

เสียงอ่านใช้เสียงไทยของอุปกรณ์ โดยเลือก Microsoft เปรมวดีให้อัตโนมัติเมื่อมีเสียงนี้ สามารถเลือกเสียงและปรับความเร็วได้ในปรับการใช้งาน แอปไม่ส่งข้อมูลไปฐานข้อมูลหรือบริการสร้างเสียงของแอปเอง บริการเสียงของอุปกรณ์อาจใช้เครือข่ายตามการตั้งค่าของระบบนั้น

## แบบนำทางการเขียน

เส้นปากกาเป็นเส้นโค้งที่กำหนดจุดเริ่ม ทิศวนหัว และลำดับการยกมือไว้โดยตรง ไม่หาเส้นทางจาก skeleton ของฟอนต์ เพราะจุดแยกและวงหัวอาจทำให้การลากย้อนกลับผิดทาง ใช้แบบ Sarabun และตำแหน่ง/สเกลร่วมกับลูกศร ตรวจจุดเส้นว่าอยู่ภายในรูปอักษรจริง และตรวจทิศวนหัวแยกจากการตรวจตำแหน่ง หลักการอ้างอิง **คู่มือการสอนอ่านเขียนโดยการแจกลูกสะกดคำ** สถาบันภาษาไทย สพฐ. 2559 หน้า 21–24 และ 55: https://bky.ac.th/home/download/bkyfile1657595457_47922.pdf

ข/ช วนหัวตามเข็มนาฬิกาก่อนโค้งครอบหัว; อ/ฮ วนหัวทวนเข็มนาฬิกาก่อนลากลง; ล/ส ย้อนขาขวาขึ้นไปโค้งส่วนบนโดยตั้งใจ และ ส ยกมือเติมหางเป็นเส้นที่ 2; สระอือเติมขีดขวาก่อนขีดซ้าย มีปุ่ม **ดูการลากช้า ๆ** แสดงปากกาทีละเส้นและหยุดพักเมื่อยกมือ ปุ่มหยุดสาธิตและการแตะเขียนหยุดภาพสาธิตได้ทันที การสาธิตไม่เปลี่ยนหรือลบเส้นของนักเรียน

เส้นประขีดกลางในแบบสระเป็นตำแหน่งพยัญชนะ ไม่ใช่เส้นที่ต้องเขียน กิจกรรมนี้ยังเป็นการฝึกตามแบบและไม่ตรวจลายมืออัตโนมัติ

ตัวอักษรในทั้ง 3 กิจกรรมผสมคำใช้ขนาดเดียวกันสำหรับพยัญชนะ สระ คำตัวอย่าง คำที่สร้าง และตัวเลือก โดยคงสัดส่วนสระตามแบบอักษรและเพิ่มขนาดพร้อมกันเมื่อเปิดตัวหนังสือใหญ่ขึ้น

ประสมคำง่ายจัดตัวเลือกพยัญชนะและสระเป็นสองคอลัมน์ในแถวเดียวกัน ทั้งคอมพิวเตอร์และมือถือ

### ปรับชุดเส้นนำทาง

แก้เส้นปากกาใน `scripts/writing-strokes.mjs` แล้วสร้าง `src/writingGeometry.json` ใหม่ด้วย `node scripts/fit-writing-guides.mjs` หลังติดตั้ง Python package `fonttools` ชื่อคำสั่งเดิมยังใช้ได้ แต่ไม่มีการ fit หรือเปลี่ยนเส้นปากกาอัตโนมัติแล้ว การสร้างข้อมูลนี้เป็นขั้นตอนพัฒนาเท่านั้น ไม่ต้องใช้ Python ตอนเปิดแอปหรือ build เว็บ โครงร่างฟอนต์และเส้นนำทางถูกจัดวางด้วย `writingLayout.ts` เดียวกัน ใบอนุญาตฟอนต์อยู่ใน `public/Sarabun-OFL.txt`

## ภาพประกอบบทเรียน

ภาพพยัญชนะทั้ง 16 ตัวใช้ SVG ชุดเดียวกันใน `ConsonantArt.tsx` รูปร่างเต็มตัวและส่วนสำคัญของสัตว์/สิ่งของแสดงชัดเจน เช่น หงอนและเหนียงไก่ งวงช้าง ลายเสือ หางลิง และฐานพาน ภาพใช้สัดส่วนกรอบ 200 × 200 ลายเส้นและโทนสีเดียวกัน และถูกเรียกใช้ร่วมกันทั้งการ์ด รู้จักกันก่อน คำถาม ผสมคำ และกรอบฝึกเขียน ตัวมาสคอตหนังสืออยู่ใน `BookFriend.tsx` ลบภาพของบทเรียนเก่าที่ไม่ได้ใช้แล้ว

ภาพสัตว์ 10 ชนิดอยู่ใน `AnimalArt.tsx` ใช้สัดส่วนธรรมชาติ ตาและหัวเล็กลง รายละเอียดเฉพาะชนิด เช่น กีบม้า งวงและเท้าช้าง ลายเสือ เส้นขน หนวดหนู ปีกผึ้ง และกระดองเต่า สีใกล้เคียงธรรมชาติและเส้นขอบบางกว่าภาพสิ่งของ ตัวรับภาพร่วมยังคงเป็น `ConsonantArt.tsx`
